## 二、發現

1. 原檔嘅冷機「選型」其實**不在這一頁**：此頁係 **冷負荷密度 → 總冷量 → 冷機台數配置** 嘅前期估算，
   加上 COP／IPLV 定義與真實項目參考值；機型目錄（MHI 等）係 App 後來加入嘅。
2. **IPLV 權重 0.01／0.42／0.45／0.12 與 AHRI 550/590 一致**（1% @100%、42% @75%、45% @50%、12% @25%）；
   對應冷凝水溫 29.4／23.9／18.3／18.3 °C 亦係標準測試條件 → App 可直接沿用並補上水溫欄。
3. 原檔 `COP = 3.516 / (ikW/RT)` 用 3.516，而 App 其他地方用 **3.517**（100 RT = 351.7 kW）。
   兩者差 0.03%，屬原檔內部不一致，需在文件與向量中記錄。

## 三、建議改法（照原檔排位、現代 UI）

1. **冷負荷密度卡（照原檔 G:I）** — 密度單位選擇（W/m²、ft²/RT、m²/kW、ft²/HP）＋ 面積輸入 →
   即時顯示 kW／RT／HP／Btu/h／kcal/h，並顯示所需冷機台數（可輸入單機容量，如 850 RT）。
2. **設計指標表卡（照原檔 L:N）** — 32 行中文建築類型指標表，可**點選一行自動填入密度**
   （或用範圍中值），成為密度卡嘅輸入來源。
3. **容量換算卡（照原檔 B:F）** — kW ↔ RT／HP／Btu/h／kcal/h 互換（與密度卡共用換算函數）。
4. **冷機效率卡（照原檔 AA:AE）** — 保留現有 COP／kW/RT 與 IPLV／NPLV，補上**四點權重與冷凝水溫欄**，
   並列出 `COP = 3.516 / (ikW/RT)` 與 ARI 550/590 出處。
5. **項目參考值表（照原檔 P:Y）** — 待你決定是否收錄（見問題）；若不收錄，改為「自行輸入參考值」欄位。
6. **電氣發熱量（照原檔 AG）** — 建議放入電氣／馬達模組嘅摺疊區，唔放在冷機頁。

**功能影響評估**：新增兩條純換算關係（密度↔負荷、面積單位）與一張查表；引擎已有單位換算與 AHRI IPLV，
只係把原檔嘅建築指標表與權重補齊。無改動現有冷機計算。

**驗收**：以原檔快取值核對 —— 南京萬豪 GFA 79000 m²、空調面積 39500 m²、總冷量 2180 RT、
配置 3×850RT、密度 323／88.4／177.7／194 W/m²；HT Bay 52763 m² → 2100 RT → 233.35 W/m²；
IPLV 權重四點；`COP = 3.516/(ikW/RT)`。
