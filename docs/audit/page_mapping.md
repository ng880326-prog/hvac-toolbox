## 改造次序（逐頁樣版兩步法）
1. 先做 **#1 Coil**（您最重視且差距最大的頁）→ 成為「並排情境＋摺疊」樣版
2. 再 #2 Pipe、#3 Air-side（同型樣版）
3. 其餘按 P1 → P2 批次套用

## 每次執行模式（一句話啟動）
「做 Coil」 / 「做 Pipe」 → 我讀該頁 dump＋現模組 → 依原表版面重建 → 跑測試 → 交付。
