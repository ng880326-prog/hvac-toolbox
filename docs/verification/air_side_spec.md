# Air-side 模組規格（輸入／輸出欄位清單）

範圍：`Air-side` 工作表（含 `Psychrometric Chart`／`Supporting 1–6.1` 供濕空氣物性之公式庫）。
公式編號 **F1–F21** 對應 `docs/verification/psychro_air.md` 之驗證結果。儲存格參考為 Excel 原始位置，供移植對照。

## 1. 全域設定與公式庫（F#）

| 公式 # | 名稱 | 公式（SI） | 驗證判定 |
|---|---|---|---|
| F1 | 飽和水蒸氣壓 pws（kPa） | `EXP(−5800.2206/T + 1.3914993 − 0.048640239·T + 4.1764768e-5·T² − 1.4452093e-8·T³ + 6.5459673·lnT)/1000`，T=K | ✅（0–200 ℃；<0 ℃ 需改冰面係數） |
| F2 | 含濕量 W（kg/kg） | `0.62198·pw/(p−pw)` | ✅ |
| F3 | 焓 h（kJ/kg） | `1.006·t + W·(2501+1.805·t)` | ✅（1997 ASHRAE 係數組） |
| F4 | 比容 v（m³/kg） | `0.2871·(t+273.15)·(1+1.6078·W)/p` | ✅ |
| F5 | 密度 ρ（kg/m³） | `(1+W)/v` | ✅ |
| F6 | 濕球式（W 與 t* 關係） | `W = ((2501−2.381·t*)·Ws(t*) − (t−t*))/(2501+1.805·t−4.186·t*)` | ✅（割線迭代） |
| F7 | 飽和度 μ | `μ = W/Ws` | ✅ |
| F8 | 相對濕度 φ（%） | `μ/(1−(1−μ)·pws/p)·100` | ✅ |
| F9 | 水蒸氣分壓 pw（kPa） | `p·W/(0.62198+W)` | ✅ |
| F10 | 露點 tdp（℃） | `6.54 + 14.526·ln(pw) + 0.7389·ln(pw)² + 0.09486·ln(pw)³ + 0.4569·pw^0.1984` | ✅（有效 0–93 ℃；pw=0 → 需護衛） |
| F11 | 雷諾數 Re | `ρ·v·D/μ` | ✅ |
| F12 | 動黏度 μ（Pa·s）查表 | 13 ℃: 17.78e-6；24 ℃: 18.312e-6；28 ℃: 18.474e-6；**37 ℃: 18.474e-6（❌ 應為 ~18.94e-6）** | ⚠️/❌ |
| F13 | 動黏度 ν（m²/s） | `μ/ρ` | ✅ |
| F14 | Haaland 摩阻係數 λ | `(1/(−1.8·log₁₀(6.9/Re + ((k/D)/3.71)^1.11)))²` | ✅ |
| F15 | 單位長度壓損 Δp/L（Pa/m） | `λ·0.5·ρ·16·Q²/(π²·D⁵)`（≡ λρv²/2D） | ✅ |
| F16 | 矩形當量直徑 De（m） | `1.453·A^0.6/P^0.2`（≡ 1.265·(ab)^0.6/(a+b)^0.2，CIBSE） | ⚠️（與 Huebscher 1.30 式差 ≤2 %） |
| F17 | 扁圓面積 A（m²） | `π(h/2)² + (W−h)·h` | ✅ |
| F18 | 扁圓周長 P（m） | `π·h + 2·(W−h)` | ✅ |
| F19 | 扁圓當量直徑（m） | `1.55·A^0.625/P^0.25`（ASHRAE，標註於 BP11） | ✅ |
| F20 | 速度壓力 Pv（Pa） | `0.5·ρ·v²` | ✅ |
| F21 | 擴散器/百葉面積 | `A = Q/(v·η)` | ✅（方法論） |

## 4. 移植注意事項（對照 psychro_air.md §D）
1. F1/F10 加溫度分支與域護衛（<0 ℃ 冰面係數；pw=0 回空值）。
2. F12 之 37 ℃ 值改 18.94e-6。
3. 求解器（濕球/乾球割線）加 bracket 或迭代上限＋「已收斂即停」。
4. F16 若對外宣稱 ASHRAE 體系，改 Huebscher 1.30 式（或保留並標註 CIBSE）。
5. 所有濕空氣函數固定使用 1997 係數組（0.62198 / 2501 / 1.805 / 2.381），勿與現行 ASHRAE（0.621945 / 2501+1.86 / 2.326）混用於同一狀態計算。
