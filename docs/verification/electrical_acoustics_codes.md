## 1. 馬達滿載電流（Motor 表）

### Excel 原文
- `Motor!Y6`（安培計算核心公式）：
  `IF(OR(X6<$B$33,X6=$B$33), X6*1000/$C$18/0.85, X6*1000/(3)^0.5/$C$19/0.85)`
- 參數：`B33 = 2.2 kW`（1Ø 最大額定）、`C18 = 220 V`（1Ø）、`C19 = 380 V`（3Ø，由 `VLOOKUP(C18,BN1:BO3,2)` 得來）
- 對應功率→電流雙向轉換（BI20:BJ24）：
  - 1Ø：`I = P*1000/(220*0.85)`、`P = I*220*0.85/1000`
  - 3Ø：`I = P*1000/(√3*380*0.85)`、`P = I*√3*380*0.85/1000`

### 標準公式
- 1Ø：`I = P×1000 / (V·pf·η)`
- 3Ø：`I = P×1000 / (√3·V·pf·η)`
- 標準慣例：IEC 60034-1 給出效率/功率因數測試方法但不固定 pf；NEC 430.250（3Ø 滿載電流表）與多數工程手冊的 FLA 表已內建「典型 η×pf」的合成值；設計階段常用 pf=0.80–0.90、η 隨額定上升（0.75 kW≈0.78–0.82 → 200 kW≈0.95–0.96）。

### 驗證結果
- 代入 5.5 kW、380 V、pf=0.85：`I = 5500/(1.73205×380×0.85) = 9.83 A`，與表內 `Y17=9.831` 完全一致 ✅（公式數學正確，η=1）。
- **問題 1：省略 η。** 典型 IE3 5.5 kW 4 極馬達 η≈0.87、pf≈0.84 → `I = 5500/(√3×380×0.84×0.87) = 11.4 A`。表值低估 ~14%；小型馬達更嚴重（見第 7 節比較表）。
- **問題 2：「η 分級」的實際鍵值不是 kW。** 表內 `C22/C23/C24 = 0.65/0.70/0.75`（標籤「Motor Efficiency」），由 `AH15 = IF(AND(AH8<1,AH8>=0),$C$22,IF(AH8>2,$C$24,IF(OR(AH8>1,AH8<=2),$C$23)))` 選取，而 `AH8` 是**風量（m³/s）**（`B22 "<1000L/s"`、`B23 "1000~2000"`、`B24 ">2000L/s"`）。即「<1 / 1–2 / >2」三檔是風量檔，且只用在風機軸功率公式 `AH21`（Fan Power），**與安培計算完全無關**。任務描述中「η 分級（<1kW、1-2kW、>2kW）」與表內實作不符，轉型時必須釐清。

### 出處
- IEC 60034-1 / IEC 60034-30-1（IE1–IE4 效率等級）：https://www.iec.ch/
- NEC 430.250（Full-Load Current, Three-Phase AC Motors）：https://www.nfpa.org/
- Engineering Toolbox – Electrical Motors Full Load Amps：https://www.engineeringtoolbox.com/elctrical-motor-full-load-current-d_1499.html
- AxFlow – Typical 3-Phase FL Amps (50 Hz, 220/380/400/415/440 V)：https://www.axflow.com/en-lt/support/engineering-toolbox/typical-3-phase-fl-amps---50-hz/

### 判定：⚠️
### 修正建議
1. 安培計算加入 η：`I = P×1000/(√3·V·pf·η)`；η 與 pf 做成使用者可編輯，預設值按額定分檔（如：<1 kW：η=0.75/pf=0.80；1–7.5 kW：η=0.85/pf=0.83；7.5–37 kW：η=0.90/pf=0.85；>37 kW：η=0.93/pf=0.87，均為保守預設）。
2. 或保留「P/(√3·V·pf)」為快速估算模式，但在 UI 明確標示「未含效率，實際電流約高 10–25%」，並提供「含 η 模式」切換。
3. 「Motor Efficiency 0.65/0.70/0.75」按風量分檔僅適用於小型風機配套估算；正式模組應按 IEC 60034-30-1 效率等級選 η。

## 2. 馬達起動方式選擇（Motor 表 AA6 / B34:B36 / B27:C30）

### Excel 原文
```
AA6 = IF(OR(AND(X6>$B$34,X6<$B$35),X6=$B$35),"DOL",
         IF(OR(X6<$B$34,X6=$B$34),"fuse",
         IF(OR(X6=$B$36,X6>$B$36),"Auto-Tx","Υ/Δ")))
```
界限：`B34 = 2.5 kW`（fuse 最大）、`B35 = 3 kW`（DOL 最大）、`B36 = 160 kW`（Auto-Tx 最小）。
→ **P ≤ 2.5 kW：fuse；2.5 < P ≤ 3 kW：DOL；3 < P < 160 kW：Υ/Δ；P ≥ 160 kW：Auto-Tx。**

起動電流乘數（B27:C30）：DOL = **6**、Υ/Δ = **2.5**、Auto-Tx = **1.5**、VSD = **1.3**（`AB6 = IF(AA6="fuse",Y6*$C$27,VLOOKUP(AA6,$B$27:$C$30,2,FALSE)*Y6)`）。

### 慣例對照
- DOL 起動電流一般為 6–8×FLC（IEC 60034-12 起動特性；NEMA code letter 表）；採用 6× 為常用下限，✅ 合理。
- Υ/Δ 起動電流 ≈ DOL 的 1/3 ≈ 2.0–2.7×FLC；取 2.5× ✅。
- 自耦變壓器：50% 抽頭 ≈ 0.5²×6 = 1.5×；65% 抽頭 ≈ 2.5×；取 1.5× 相當於 50% 抽頭，✅ 合理（偏保守）。
- VSD 起動電流一般限制在 1.1–1.5×FLC；取 1.3× ✅。
- 功率界限屬設計慣例而非規範強制：歐洲慣例 DOL 常用至 **4 kW**（部分地區/電力公司允許 7.5 kW），星三角自 ~3–4 kW 起用，特大馬達（≥100–200 kW）才用自耦/軟啟動/VSD。本表 DOL 帶只有 2.5–3 kW（過窄、近乎跳過 DOL），fuse 保護帶至 2.5 kW 亦偏保守（通常僅 ≤0.5–1 kW 的小馬達直接以 fuse 保護）。

### 出處
- KSB – Starting method（離心泵辭典）：https://www.ksb.com/en-global/centrifugal-pump-lexicon/article/starting-method-1118200/
- ABB《Low voltage motors – Motor guide》起動方式章節（DOL/YD/自耦/軟啟動比較）
- IEC 60034-12（起動特性分類）

### 判定：✅（乘數）／⚠️（界限為保守設計慣例）
### 修正建議
- 乘數保留；界限改為**可配置參數**（預設可沿用 2.5/3/160，或提供「慣例模式」：DOL ≤ 4 kW、Y/Δ 4–160 kW、Auto-Tx ≥ 160 kW）。
- 起動方式顯示時同時輸出「起動電流 = FLA × 乘數」與 MCB/斷路器建議（現表已有 AC 欄），轉型時保留。

## 3. 換算常數 0.09804139432 / 9.804139432（Motor 表 BD20:BF23）

### Excel 原文
```
BE20 = BD20*0.09804139432     ' m → bar
BF20 = BD20*9.804139432       ' m → kPa
BG20 = BF20*0.001             ' kPa → MPa
T16  = T15/9.804139432/1000   ' kPa → m
```
（BD/BE/BF/BG 依 `$D$11` 單位標籤路由，單位鏈：m / bar / kPa / MPa）

### 性質澄清：這是「壓力水頭」換算，不是扭矩
- 標準：1 mH₂O（4°C）= **9.80665 kPa** = **0.0980665 bar**（g_n = 9.80665 m/s²，BIPM SI）。
- 表內 9.804139432 / 0.09804139432（兩者互為 ÷100 關係，同源），相對標準值誤差 = (9.80665−9.804139432)/9.80665 = **−0.0256%（−256 ppm）**。來源應為誤抄的非標準重力值（g=9.804139432，非任何常用定義值）。
- **扭矩換算（若 app 未來需要）：1 kgf·m = 9.80665 N·m；1 N·m = 0.1019716 kgf·m。** 表內 0.09804139432 **不是** N·m→kgf·m 係數，若誤用於扭矩會造成 −3.85% 系統誤差。

### 出處
- BIPM SI Brochure（standard acceleration of gravity 9.80665 m/s²）：https://www.bipm.org/en/publications/si-brochure
- NIST SP 811（換算係數）：https://www.nist.gov/pml/special-publication-811

### 判定：⚠️（非標準常數、文義需澄清）
### 修正建議
- 水頭換算改為 `1 mH₂O = 9.80665 kPa = 0.0980665 bar`（相對差 0.026%，雖小但既然要上架，應與標準一致）。
- 若提供扭矩轉換單元，使用 `kgf·m ↔ N·m = ×9.80665 / ÷9.80665`（或 N·m→kgf·m ×0.1019716），並在 UI 標示 kgf 基於標準重力。

## 5. 聲學公式（Acoustics 表，3 條）

### Excel 原文
```
F10: IF(F6*F7*F8>0, F6-10*LOG(4*PI()*(F7)^2)+10*LOG(F8), "-")     ' SPLr
L10: IF(L6*L7*L8>0, L6+10*LOG(4*PI()*(L7)^2)-10*LOG(L8), "-")     ' SWL
R11: IF(R6>0,10*LOG(10^(0.1*R6)+10^(0.1*R7)+10^(0.1*R8)+10^(0.1*R9),10),"-")  ' SLN
```
指向因數表：Qθ = 1（free propagation）／2（1-face rebound）／4（2-face rebound）／8（3-face rebound）。

### 標準公式
- `Lp = Lw + 10·log10(Qθ/(4πr²)) = Lw − 10·log10(4πr²) + 10·log10(Qθ)` ✅
- 反解 `Lw = Lp + 10·log10(4πr²) − 10·log10(Qθ)` ✅
- 非相干 dB 疊加 `LΣ = 10·log10(Σ 10^(0.1·Li))` ✅
- Qθ：1 = 全自由場（球面）；2 = 半空間（1 反射面）；4 = 1/4 空間（2 反射面）；8 = 1/8 空間（3 反射面）✅
- Excel 實作細節：`10*LOG(x)` 與 `LOG(x,10)` 均為以 10 為底 ✅；`10^(0.1*Li)` 正確。

### 適用條件（轉型時需在 UI 標示）
- 點聲源、遠場、自由場（或理想反射面）假設；不含大氣吸收、障礙物/隔音損失、地面吸收；r→0 時公式發散（須限制 r ≥ 0.5 m 之類）；dB(A) 標示假設各頻帶同權重，直接相加為估算值。

### 出處
- ASHRAE Handbook – Fundamentals, Ch. 8 Sound and Vibration：https://www.ashrae.org/technical-resources/ashrae-handbook
- Bies & Hansen, *Engineering Noise Control*（指向因數與半球傳播）
- Engineering Toolbox – Sound Propagation (Inverse Square Law)：https://www.engineeringtoolbox.com/sound-propagation-d_64.html
- ISO 3744（聲功率測定，自由場/反射面方法）

### 判定：✅（3/3，附使用條件注意事項）

→ 現行值比表內舊值**高 30–60%**（例：A 型 20~32 層舊表 35000~40000 vs 現行 39600~45800；B1 舊 16000~20000 vs 現行 25300~27500）。**沿用舊值會嚴重低估送風量，屬合規性問題。**
- 現行標準其他關鍵要求：§3.4.1 **設計風量 ≥ 1.2× 計算風量**（強制條文）；§3.4.5~3.4.8 計算法（`Lj = L1+L2`，`L1 = Ak·v·N1`；漏風量 `L2 = 0.827·A·ΔP^(1/n)·1.25·N2`，n=2；常閉閥漏風 `L3 = 0.083·Af·N3`）；門洞風速 0.7 / 1.0 / 0.6(Al/Ag+1) m/s 依情境；§3.4.2 條文說明**明確要求表值選用採線性插值**（印證本表內插做法方向正確）；單扇門 ×0.75 保留 ✅；「≥2 出入口 ×1.5~1.75」已不在現行表註中（現行改以計算法處理，表註僅對固定門配置有效）。
- **D 型 = "30" m³/h·m² ❌ 誤用**：30 m³/(h·m²) 是**封閉避難層**加壓送風量（GB 50045-95 §8.3.5 / GB 51251-2017 §3.4.3「避難層淨面積每平方米 ≥30 m³/h」），不是「樓梯間自然排煙時前室加壓」的風量。該情境的正確值：舊版查表 8.3.2-4；現行查表 3.4.2-2（42400~44700 / 45000~48600，見上表）。
- **實作 bugs ❌**：
  1. 大小寫不一致：表中存的是 `"N/A"`，公式判 `C9="n/a"`（小寫）→ D 型時 `F9` 單位選擇、`B20` 分支全部失靈；
  2. `B24 = ROUNDUP(C10,0)`：C5=0 時 C10="-"（文字）→ `#VALUE!`；C6="D" 時 C10="30"（文字）→ 同樣 `#VALUE!`（靜態快照中 B24 已見 `#VALUE!`）；
  3. 樓層 >32 無分支：C9 會回傳 `FALSE`（舊規範上限 32 層，現行標準以高度 100 m 分界並要求 >100 m 分段設計）。
