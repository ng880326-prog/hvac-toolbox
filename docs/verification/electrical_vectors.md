## 1. 馬達滿載電流

### 1.1 3Ø 5.5 kW、380 V、pf=0.85（不含 η，與現表一致）
- 公式：`I = P×1000/(√3×V×pf) = 5500/(1.7320508×380×0.85)`
- **期望值：9.831 A**（現表 Y17 = 9.831）✅

### 1.2 同例含 η（典型 IE3：η=0.87、pf=0.84）
- `I = 5500/(√3×380×0.84×0.87)`
- **期望值：11.43 A**（比 1.1 高 16%；這是修正建議採用之輸出）

### 1.3 1Ø 1.5 kW、220 V、pf=0.85
- `I = 1500/(220×0.85)`
- **期望值：8.021 A**（現表 Y12 = 8.0214）✅

### 1.4 相位切換臨界（B33 = 2.2 kW）
- X = 2.2 kW → 1Ø：`2200/(220×0.85)` = **11.765 A**（現表 Y13 = 11.7647）✅
- X = 2.3 kW → 3Ø：`2300/(√3×380×0.85)` = **4.111 A**
- X = 2.2 kW 時 Z 欄 = "1Ø"；X = 2.3 kW 時 = "3Ø"

### 1.5 電流→功率反算（AR6 切換，BI20:BJ24）
- 1Ø、I = 10 A → `P = 10×220×0.85/1000` = **1.87 kW**
- 3Ø、I = 10 A → `P = 10×√3×380×0.85/1000` = **5.594 kW**

## 5. 聲學

### 5.1 主例（任務指定）：SWL=80 dB(A)、r=5 m、Qθ=2
- `SPLr = 80 − 10·log10(4π×5²) + 10·log10(2)`
- `10·log10(4π×25) = 10×2.49715 = 24.9715`；`10·log10(2) = 3.0103`
- **期望值：SPLr = 58.039 ≈ 58.04 dB(A)**

### 5.2 反算
- `SWL = 58.039 + 24.9715 − 3.0103` → **80.00 dB** ✅

### 5.3 Qθ 梯度（SWL=80、r=5 m）
| Qθ | 情境 | SPLr (dB) |
|---|---|---|
| 1 | 自由場 | 58.04 − 3.01 = 55.03 |
| 2 | 1 反射面 | 58.04 |
| 4 | 2 反射面 | 61.05 |
| 8 | 3 反射面 | 64.06 |

### 5.4 dB 疊加
| 輸入 (dB) | 期望 SLN |
|---|---|
| 80, 80 | 83.01 |
| 80, 85 | 86.19 |
| 80, 80, 85, 90 | 10·log10(2×10⁸+10⁸·⁵+10⁹) = 10·log10(1.51623×10⁹) = **91.81** |

### 5.5 邊界守則（轉型時應實作）
- r ≤ 0 或 Qθ ≤ 0 → 輸出「—」/錯誤訊息（現表以 `F6*F7*F8>0` 守衛 ✅）
- 疊加時任一輸入 = 0 → 視為無源（現表以 `R6>0` 啟用，若 SL2=0 則把 10^0=1 計入會造成 +0.0x dB 誤差，建議改為「>0 才納入」）

## 6. 梯間加壓送風（SPF）

### 6.1 舊規範模式（GB 50045-95 2005，維持現表邏輯）
- 案例：A 型（防煙樓梯間，前室不送風）、10 層、雙扇門、1 個出入口
  - 下限 C9=25000、上限 E9=30000
  - `C10 = C9 + (E9−C9)×(10−1)/18 = 25000 + 5000×0.5 = 27500`（= `ABS((30000−25000)×(19−10)/(19−1)−30000)` ✅）
  - 雙扇門 ×1、出入口 ×1 → **風機風量 = 27500 m³/h**
- 同例改單扇門：`27500×0.75 = 20625 m³/h`
- 同例 2 個出入口：`27500×1.5 = 41250 m³/h`
- 20 層 A 型：C9=35000、E9=40000 → `35000 + 5000×(20−20)/12 = 35000`；32 層 → **40000 m³/h**
