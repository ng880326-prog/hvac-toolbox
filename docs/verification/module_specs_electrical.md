# 模組規格：Motor / Acoustics / 梯間加壓（Module Specs）

適用：HVAC Toolbox Pro 轉型（Web app / Capacitor / Tauri）。單位與公式基準以 `docs/verification/electrical_acoustics_codes.md` 驗證結論為準（已修正項以 ✅Fix 標示）。

---

## 1. Motor（馬達選型）模組

### 1.1 子功能
- M1 滿載電流（FLA）計算（含 kW↔A 雙向）
- M2 起動方式 + 起動電流 + MCB 建議
- M3 風機/水泵軸功率與馬達額定選擇（保留 Excel 估算邏輯）
- M4 壓力水頭單位換算（m / bar / kPa / MPa）＋（可選）扭矩 kgf·m↔N·m
- M5 ER 輸送能效比（氣候分區限值查核）

### 1.2 M1 滿載電流
| 項目 | 規格 |
|---|---|
| 輸入 | P (kW, 0.1–1000)、相位（自動：≤2.2 kW→1Ø，否則 3Ø；可手動覆寫）、V（1Ø：110/200/220/230 V；3Ø：380/400/415 V，預設 380）、pf（預設 0.85）、η（✅Fix 新增：預設分檔） |
| η 預設分檔（✅Fix，保守值） | <1 kW：0.75；1–7.5 kW：0.85；7.5–37 kW：0.90；>37 kW：0.93 |
| 輸出 | FLA (A)、視在功率 (kVA)、建議電纜/斷路器粗選提示 |
| 公式 | 1Ø `I=P·1000/(V·pf·η)`；3Ø `I=P·1000/(√3·V·pf·η)` |
| 模式 | 「快速估算」= η 鎖 1 並顯示警示；「含 η」= 預設分檔（✅Fix） |
| 單位 | kW、V、A、-（pf/η 無因次） |

### 1.3 M2 起動方式
| 項目 | 規格 |
|---|---|
| 輸入 | P (kW)、是否 VSD（bool） |
| 邏輯（可配置 ✅Fix） | 預設慣例：P≤2.5 kW→fuse；2.5<P≤4 kW→DOL（✅Fix：原表上限 3 kW）；4<P<160 kW→Y/Δ；P≥160 kW→Auto-Tx；VSD 覆寫 |
| 乘數（固定常數表） | fuse/DOL=6；Y/Δ=2.5；Auto-Tx=1.5；VSD=1.3 |
| 輸出 | 起動方式、I_start = FLA×乘數 (A)、MCB 框架建議（20/32/40/50/63/80/100/125/160/200/250/315/400/630/800/1000 A 選 ≥1.25×FLA 且 ≥I_start 之電磁特性可承受者——僅提示，最終由電氣工程師定） |
| 單位 | kW、A |

### 1.4 M3 軸功率與額定選擇
| 項目 | 規格 |
|---|---|
| 風機 | 輸入 Q (m³/s)、ΔP_total (Pa)、η_fan、η_motor、S.F.；公式 `P = S.F.·Q·ΔP/(1000·ηf·ηm)` kW；輸出建議額定（自額定表 X6:X39 選最小 ≥P 值，✅Fix：補 250 kW） |
| 水泵 | 輸入 Q (kg/s 或 m³/h)、H (m)、η_pump、S.F.；公式 `P = S.F.·Q(kg/s)·H·g/(1000·η)`，g=9.80665（✅Fix） |
| 額定表 | kW 序列（✅Fix：標示 IEC 60072-1 優選值；保留 3.7/9/25/33/63/225 為「舊英制沿革值」標籤）；FLA 表提供「估算(η=1)」與「典型含 η」雙模式（✅Fix） |
| 單位 | m³/s、Pa、m、kW、kg/s |

### 1.5 M4 單位換算
| 轉換 | 係數（✅Fix 標準重力） |
|---|---|
| mH₂O→kPa | ×9.80665 |
| mH₂O→bar | ×0.0980665 |
| bar→kPa | ×100 |
| kPa→MPa | ×0.001 |
| kgf·m→N·m（可選新增） | ×9.80665 |
| N·m→kgf·m（可選新增） | ×0.1019716 |

### 1.6 M5 ER（含新舊法規雙模式 ✅Fix）
| 模式 | 公式 | 限值 |
|---|---|---|
| 舊版 GB 50189-2005 §5.3.27（標「僅供參考」） | `ER = 0.002342·H/(ΔT·η)` | 兩管制熱水：嚴寒 0.00577／寒冷+夏熱冬冷 0.00433／夏熱冬暖 0.00865；四管制熱水 0.00673；空調冷水 0.0241 |
| 現行（✅Fix 新增，GB 50189-2015 §4.3.3 / GB 50736-2012 §8.5.12） | EHR-h / EC(H)R-a（依 A、B、α、ΣL 係數） | 依標準表 4.3.9-2 / 8.5.12-2~5 |
| 輸入 | 管系類型（兩管制熱水/四管制熱水/冷水）、氣候分區（嚴寒/寒冷/夏熱冬冷/夏熱冬暖/溫和）、H (m)、ΔT (°C)、η |
| 輸出 | ER 值、限值、✅滿足/❌不滿足、規範版本標示 |

## 2. Acoustics（聲學）模組

| 子功能 | 輸入 | 輸出 | 公式 |
|---|---|---|---|
| A1 距離衰減 | SWL (dB(A))、r (m, >0)、Qθ (1/2/4/8 選單＋說明) | SPLr (dB(A)) | `SPLr = SWL − 10·log10(4πr²) + 10·log10(Qθ)` |
| A2 聲功率反推 | SPLr、r、Qθ | SWL | `SWL = SPLr + 10·log10(4πr²) − 10·log10(Qθ)` |
| A3 dB 疊加 | 2–10 個聲源 dB 值 | SL_N | `SL_N = 10·log10(Σ 10^(0.1·SLi))`（僅納入 >0 者 ✅Fix） |
| 常數表 | Qθ：1 自由場／2 單面反射（牆或地）／4 雙面（牆+地或兩牆）／8 三面（角） | | |
| 守衛 | r ≤ 0 或 Qθ ≤ 0 → 不計算；r < 0.5 m 提示「近場公式不適用」 | | |
| 注意事項（UI 標示） | 點聲源遠場、自由場假設；未含大氣吸收/障礙物；dB(A) 疊加為同權重估算 | | |
| 單位 | dB(A)、m | | |

## 3. Stair Pressurization（梯間加壓送風估算）模組 — 原 SPF(PRC)

### 3.1 規範版本選擇（✅Fix 核心改動）
- 模式 1：**GB 51251-2017（現行，預設）**
- 模式 2：GB 50045-95 (2005 版)（標示「已廢止，僅供歷史對照」）

### 3.2 輸入
| 欄位 | 規格 |
|---|---|
| 樓梯類型 | A 防煙樓梯間（前室不送風）／B1 防煙樓梯間及合用前室（樓梯間）／B2 同上（合用前室）／C 消防電梯間前室／D 樓梯間自然通風，前室/合用前室加壓 |
| 樓層數 | 整數 1–50；>32 或對應高度 >100 m → 提示「應分段設計」 |
| 建築高度 h | m（模式 1 用；或由樓層數估算 3 m/層，標示假設） |
| 門型 | 單扇（×0.75）／雙扇（×1） |
| 出入口數量 | 1 或 >1（模式 2 舊規範 ×1.5；模式 1 提示「多出入口應以計算法（§3.4.5~3.4.8）覆核」） |
| 風道材料/防火門漏風（可選） | 影響範圍選取下限/上限的工程判斷參數 |

### 3.3 查表數據（模式 2 舊規範，與 Excel 一致 ✅）
| 類型 | <20 層 | 20~32 層 |
|---|---|---|
| A | 25000~30000 | 35000~40000 |
| B1 | 16000~20000 | 20000~25000 |
| B2 | 12000~16000 | 18000~22000 |
| C | 15000~20000 | 22000~27000 |

### 3.4 查表數據（模式 1 現行 ✅Fix，GB 51251-2017 表 3.4.2，m³/h）
| 類型 | 24<h≤50 m | 50<h≤100 m |
|---|---|---|
| A（表 3.4.2-3） | 36100~39200 | 39600~45800 |
| B1（表 3.4.2-4 樓梯間） | 25300~27500 | 27800~32200 |
| B2（表 3.4.2-4 前室） | 24800~25800 | 26000~28100 |
| C（表 3.4.2-1） | 35400~36900 | 37100~40200 |
| D（表 3.4.2-2） | 42400~44700 | 45000~48600 |

### 3.5 計算邏輯
1. 依模式選表；模式 1 以 h 線性內插（依條文說明 §3.4.2），模式 2 以樓層內插（同 Excel：`C9+(E9−C9)·(n−1)/18` 或 `·(n−20)/12`）。
2. 修正：單扇門 ×0.75；（模式 2）出入口 >1 ×1.5。
3. **模式 1 輸出「計算風量」後，設計風量 = ×1.2**（§3.4.1 強制條文）。
4. 結果四捨五入至整數 m³/h（ROUNDUP）。
5. D 型 ✅Fix：查表 3.4.2-2（舊模式查 8.3.2-4），**刪除 "30 m³/h·m²" 誤用**；避難層 30 m³/(h·m²) 另立輸入項（淨面積 → 風量）。

### 3.6 輸出
- 基本風量範圍、內插值、修正後風量、設計風量（現行模式含 1.2 係數）、門洞風速提示（0.7/1.0/0.6(Al/Ag+1) m/s）、正壓提示（樓梯間 40–50 Pa；前室 25–30 Pa）、警告（>32 層分段設計；多出入口需計算法覆核；舊規範僅供對照）。
- 單位：m³/h、層、m、Pa。

### 3.7 必須修復的 Excel bug（轉型時 ✅Fix）
1. `"N/A"` vs `"n/a"` 大小寫不一致 → 統一或改用布林/枚舉。
2. `B24 = ROUNDUP(C10,0)` 對文字運算 → 數值型內插 + 空值守衛。
3. 樓層 >32（模式 2）／h>100（模式 1）回傳 FALSE → 明確提示與封頂策略。

## 4. 模組共用規格

| 項目 | 規格 |
|---|---|
| 數值型別 | 十進位（Decimal/任意精度或 IEEE754 + 顯示捨入）；角度/對數用標準函式 |
| 空值/非法輸入 | 回傳 null + UI 錯誤訊息（對應 Excel "-" 語義），**永不顯示 #VALUE!/FALSE** |
| 單位標示 | 每欄明確單位；輸入/輸出單位可切換（SI/IP 後續版本） |
| 常數中心化 | g=9.80665、√3、π、起動乘數表、規範表值集中於常數設定檔 |
| 測試 | 以 `docs/verification/electrical_vectors.md` 全向量為自動測試基準（回歸門檻：全部通過） |
| 免責聲明 | 結果頁常駐「僅供初步估算參考」提示；防火模組強制顯示規範版本與覆核建議 |
