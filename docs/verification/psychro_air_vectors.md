# 測試向量表 —— 濕空氣（Psychrometrics）與風管（Duct）模組

來源：`analysis/sheets/07_Psychrometric Chart.txt`、`08_Supporting 1.txt`、`11_Supporting 3.txt`、`13_Supporting 4.txt`、`15_Supproting 5.txt`、`17_Supporting 6.txt`、`10_Supporting 2.1.txt`。
所有數值以工作表公式快照值（V: 欄）為準，可直接轉為 JS 測試斷言（容差建議：絕對 2e-4 或相對 1e-6）。

公式基準（必須與測試實作一致）：1997 ASHRAE F Ch.6
- pws(T) = EXP(−5800.2206/T + 1.3914993 − 0.048640239·T + 4.1764768e-5·T² − 1.4452093e-8·T³ + 6.5459673·lnT)/1000 kPa（T=K）
- W = 0.62198·pw/(p−pw)；pw = p·W/(0.62198+W)；μ = W/Ws；φ = μ/(1−(1−μ)·pws/p)·100
- v = 0.2871·(t+273.15)·(1+1.6078·W)/p m³/kg；ρ = (1+W)/v kg/m³
- h = 1.006·t + W·(2501+1.805·t) kJ/kg
- W_wb = ((2501−2.381·t*)·Ws(t*) − (t−t*))/(2501+1.805·t−4.186·t*)
- tdp(pw) = 6.54 + 14.526·ln(pw) + 0.7389·ln(pw)² + 0.09486·ln(pw)³ + 0.4569·pw^0.1984（pw=kPa，有效 0–93 ℃）
